# Mini-Projets Deep Learning avec Keras

Ce dépôt rassemble une série de 6 mini-projets pratiques réalisés avec **Keras** et **Scikit-Learn**, visant à explorer les différentes architectures de réseaux de neurones selon la nature des données.

---

## 🚀 Les 6 Exercices du Projet

1. **Portes logiques (Perceptron)** : Apprentissage de fonctions logiques de base avec un neurone simple.
2. **Classification d’Iris (MLP)** : Classification de fleurs à partir de données tabulaires (avec gestion rigoureuse de la normalisation pour éviter la fuite de données).
3. **MNIST (CNN)** : Reconnaissance de chiffres manuscrits sur des images en grilles de pixels.
4. **Fashion-MNIST (CNN)** : Classification d'images de vêtements et d'accessoires via un réseau convolutif plus poussé.
5. **Titanic (Régression/Classification tabulaire)** : Prédiction de survie des passagers à partir de données mixtes.
6. **Générateur de texte (RNN / LSTM)** : Génération de texte littéraire à partir d'un corpus de Victor Hugo.

---

## 🎯 Objectifs Pédagogiques
* **Adapter l'architecture** au type de données (tabulaires, images, texte).
* **Maîtriser le cycle de vie d'un modèle** : préparation des données, construction, entraînement, évaluation et interprétation.
* **Éviter les pièges classiques** : prévention du surapprentissage (*overfitting*), analyse des courbes de perte (*loss*) et interdiction de la fuite de données (*data leakage*).
